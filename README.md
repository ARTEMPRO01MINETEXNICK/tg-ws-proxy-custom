Локальный MTProto → WebSocket прокси для Telegram с современным интерфейсом.

## О проекте


TG WS Proxy — Custom Build — это форк проекта Flowseal/tg-ws-proxy,
переделанный под кастомный интерфейс и расширенный функциями:

- Кликабельный логотип : серый → цветной + мгновенно открывает Telegram
- Иконка в системном трее (сворачивание окна, контекстное меню)
- Тема Blue 

---

## Возможности

- Локальный MTProto прокси на 127.0.0.1:1443
- WebSocket мост к Telegram (kws*.web.telegram.org)
- Запуск Telegram в один клик через tg://proxy ссылку
- Иконка в системном трее с меню: Открыть / Подключить / Выход
- Кастомная синяя тема

---

## Требования

- Python 3.11 или выше
- Windows 10/11
- Telegram Desktop (для протокола tg://)

## Сборка .exe

Установите PyInstaller:

    pip install pyinstaller

Соберите:

    python -m PyInstaller build.spec --noconfirm --clean

Результат: файл dist/TG-WS-Proxy.exe — автономное приложение для Windows
с кастомной иконкой.

---

## Как использовать

1. Запустите приложение — прокси стартует автоматически.

2. Нажмите на логотип  в центре окна.
   Логотип станет цветным, и Telegram Desktop откроется с прокси.

3. Готово — Telegram работает через локальный прокси.

Или используйте иконку в системном трее:

- Левый клик — показать окно
- Правый клик — меню: Открыть / Подключить / Выход
- Крестик окна — сворачивает в трей (приложение продолжает работать)

## Структура проекта

    tg-ws-proxy-custom/
    ├── main.py              — точка входа, ProxyRunner
    ├── proxy/               — ядро MTProto → WebSocket
    ├── ui/
    │   ├── window.py        — главное окно, интеграция с треем
    │   ├── pages.py         — ProxyPage, LogsPage, InfoPage
    │   ├── widgets.py       — кастомные виджеты
    │   ├── theme.py         — синяя/тёмная тема
    │   ├── background.py    — фон с сеткой
    │   ├── tray.py          — системный трей
    │   ├── log_bridge.py    — логи PowerShell → UI
    │   └── proxy_store.py   — постоянное хранение ссылки
    ├── assets/              — иконки
    ├── build.spec           — конфиг PyInstaller
    └── requirements.txt

## О создании проекта 

Этот проект был создан при поддержке AI-ассистента.

Ассистент помог с:

- Дизайном кастомного интерфейса на CustomTkinter
  (layouts, виджеты, анимации, темы)
- Интеграцией оригинального ядра proxy/ в десктоп-обёртку
- Отладкой импортов, проблем с кодировкой (BOM/UTF-8) и переключением тем
- Созданием постоянного хранилища proxy-ссылки в proxy_link.txt
- Настройкой поведения окна (сворачивание в трей, логика кнопок)
- Решением проблем с кодировкой русских строк

Весь код был протестирован вручную. AI использовался как инструмент
разработки, а не как автор финального продукта.
